# AresOS — Запуск на реальном компьютере (с флешки)

AresOS — bare-metal ОС: она загружается **без Windows и эмулятора**, напрямую
через UEFI при включении ПК. Вот как её попробовать на живом железе.

> ⚠️ Важно: AresOS пока только ПОКАЗЫВАЕТ экран (ядро печатает диагностику).
> Она не пишет на диски и не трогает Windows — выключить ПК можно просто кнопкой питания.

## Что понадобится

1. Любая USB-флешка (хватит 1 ГБ). **Всё на ней будет стёрто.**
2. Файл `aresos.img` — скачай zip с образом из репозитория:
   **[dist/aresos-usb-v0.4.0.zip](https://github.com/Poncho435/AresOS/raw/arena/01a02ad5-aresos/dist/aresos-usb-v0.4.0.zip)**
   (или собери сам: `make` → `build/aresos.img`). Распакуй zip — внутри один файл `aresos.img` (~68 МБ).
   Контрольная сумма в `dist/SHA256SUMS.txt`.

> 💡 Для **виртуальной машины** флешка не нужна — см. раздел про VirtualBox ниже.

## Шаг 1. Записать образ на флешку

### Вариант А: balenaEtcher (простейший, Windows)
1. Скачай https://etcher.balena.io/ , установи.
2. «Flash from file» → выбери `aresos.img`.
3. «Select target» → твоя флешка.
4. «Flash!» → подтверди права администратора → готово.

### Вариант B: Rufus (Windows)
1. Скачай https://rufus.ie/ .
2. Устройство → флешка; «Выбор загрузки» → файл `aresos.img`.
3. **Важно:** при записи Rufus спросит режим — выбери **«DD-образ»** (не ISO!).
4. «Старт» → OK.

### Вариант C: Linux/WSL
```bash
sudo dd if=aresos.img of=/dev/sdX bs=4M conv=fsync   # sdX = флешка, СМОТРИ ВНИМАТЕЛЬНО!
```

## Шаг 2. Настроить UEFI (один раз)

AresOS грузится **только в режиме UEFI** (Windows 11 обычно уже в нём, так что это
скорее страховка) и не имеет цифровой подписи Microsoft:

1. При включении жми клавишу входа в UEFI/BIOS (`Del`/`F2` у большинства; у HP — `Esc`/`F10`).
2. Найди и выключи **Secure Boot** (раздел Security/Boot). Причина: наш загрузчик
   не подписан — иначе прошивка откажется грузить флешку. (На Windows это не влияет;
   после экспериментов можно включить обратно.)
3. Режим загрузки: **UEFI only** (CSM/Legacy — выкл, если есть такой пункт).

## Шаг 3. Загрузиться с флешки

1. Выключи ПК, вставь флешку.
2. Включай и жми клавишу **Boot Menu**:
   | Производитель | Клавиша |
   |---|---|
   | ASUS (мат.платы) | F8 |
   | Gigabyte | F12 |
   | MSI | F11 |
   | ASRock | F11 |
   | Dell | F12 |
   | Lenovo | F12 / Novo-кнопка |
   | HP | Esc, затем F9 |
   | Acer | F12 (включается в BIOS) |
3. В меню выбери строку вида **«UEFI: <имя флешки>»** (обязательно с приставкой UEFI!).

Альтернатива из Windows 11: Параметры → Система → Восстановление →
**«Особые варианты загрузки»** → Перезагрузить сейчас → «Использовать устройство» → UEFI USB.

## Что ты увидишь

1. Мелькнут строки загрузчика (`AresOS loader (BOOTX64.EFI)`);
2. Тёмно-синий консольный экран ядра:

```
  ============================================
   A r e s O S   kernel 0.1.0-m2
  ============================================
[gdt] GDT loaded ...
[idt] IDT loaded: 32 exception handlers armed
[fb] framebuffer console: ... @ ...
[mem] usable RAM total: ... MiB
[pmm] ...
AresOS init complete (M2). CPU halting
```

Это значит: твоя собственная ОС загрузилась на живом железе, проинициализировала
таблицы CPU, посчитала память и ждёт следующих этапов. 🎉

## Выход

Просто выключи/перезагрузи ПК. AresOS ничего не записывает на диски.

## Если не грузится

| Симптом | Причина | Решение |
|---|---|---|
| Флешки нет в Boot Menu | образ записан не в DD-режиме | переписать Rufus в режиме DD / Etcher |
| «Security Violation» / откат в меню | Secure Boot включён | выключить в UEFI (шаг 2) |
| Мигает и уходит в Windows | выбрана не UEFI-строка флешки | выбрать «UEFI: флешка» |
| Чёрный экран сразу | старая прошивка без GOP | редко; скажи мне — добавлю текстовый режим VGA |

Сфотографируй экран и пришли — разберём любой случай.

## Запуск в VirtualBox (простой путь — VMDK, без командной строки)

1. Скачай и распакуй **[aresos-vm-v0.4.0.zip](https://github.com/Poncho435/AresOS/raw/arena/01a02ad5-aresos/dist/aresos-vm-v0.4.0.zip)**
   — внутри два файла: `aresos.vmdk` и `aresos.img` (оба нужны, в одной папке!).
2. VirtualBox → ВМ: Тип **Other**, Версия **Other/Unknown (64-bit)**, 256 МБ, **✔ EFI**.
3. **Настроить → Носители** → **Контроллер: SATA** → «добавить жёсткий диск» →
   **«Выбрать существующий»** → **Добавить** → выбери **`aresos.vmdk`** → Выбрать.
4. **Запустить** → рабочий стол AresOS (окно таскается мышью).

> Раньше тут была конвертация через PowerShell (`VBoxManage convertfromraw`) —
> больше не нужна: `aresos.vmdk` — это текстовый дескриптор, который подцепляет
> raw-образ как есть.

> ⚠️ ISO в CD-приводе прошивка VBox пока не принимает (`Not Found`) — известная
> проблема нашего ISO-генератора; используй VMDK.
