# AresOS

64-битная операционная система «голого железа» (x86-64): собственное ядро на
C + ассемблере (GAS), собственный UEFI-загрузчик, живой графический рабочий
стол — и конечная цель: **запускать Windows PE-приложения (.exe)** через
собственный слой совместимости WinAPI.

> A 64-bit bare-metal OS in C + assembly with a custom UEFI bootloader and a
> live graphical desktop, aiming to run Windows PE executables via its own
> WinAPI compatibility layer.

## Текущая версия — v0.7.0

Загружается за пару секунд и сразу встречает **Установщиком**: он создаёт
системные папки и файлы с красивым прогрессом — а есть и **Центр обновления**.
Дальше — полноценный стеклянный стол в **Full HD 1920×1080** (выбор
разрешения в Настройках запоминается прямо в **UEFI NVRAM** и переживает
перезагрузку). Новое: **Настройки** (разрешение, масштаб интерфейса
100/150/200%, обои, скорость и ускорение мыши), **настоящая файловая
система ramfs**: свои папки и файлы создаются мышкой, читаются и даже
дописываются (мини-редактор, F2 = сохранить), **60 FPS** (таймер 1000 Гц,
пэйсинг 16 мс, мгновенный курсор) и **русская раскладка Alt+Shift**.
Каждое окно — **отдельный процесс ядра**, закрывается по **Alt+F4**.
Под капотом: ACPI/APIC, планировщик, куча, PE32+ .exe, UEFI Runtime
Services для настроек и перезагрузки.

## Статус этапов

- ✅ **M0** — инфраструктура: кросс-тулчейн и свои Python-инструменты
  (elf2efi, mkesp, mkiso, mkvmdk, mkpe, генератор кириллического шрифта)
- ✅ **M1** — UEFI-загрузчик (BOOTX64.EFI): ELF-парсер, GOP-графика,
  поиск ACPI RSDP, ExitBootServices
- ✅ **M2** — ядро: serial, kprintf, framebuffer-консоль, GDT, IDT,
  саморасшифровывающиеся дампы исключений
- ✅ **M2.5 (бонус)** — прототип рабочего стола: обои, панель, док, окна, мышь
- ✅ **M3** — память: PMM (bitmap), свои таблицы страниц, kernel heap
  (стресс: 1 000 000 операций, утечек 0) — *higher-half вынесен в M3.1*
- ✅ **M4** — прерывания и время: ACPI/MADT, LAPIC-таймер 1000 Гц с калибровкой
  по PIT и авто-откатом на PIC/PIT, IOAPIC-маршрутизация клавиатуры и мыши
- ✅ **M5** — многозадачность: планировщик round-robin с вытеснением тиком,
  ядровые потоки на стеках 32 КиБ, фоновые демоны, диспетчер задач
- 🎨 **v0.5.x (полировка десктопа)** — UI «midnight aurora», приложение
  «Логи системы», запуск программ значками, закрытие окон красной ×,
  полный русский интерфейс, горячие фиксы по фото из VirtualBox
- 🪟 **v0.6.3 «glass aurora»** — окна как отдельные процессы ядра,
  мульти-запуск приложений, стеклянный UI (альфа-прозрачность, тени,
  скругления), двойная буферизация без мерцания, Alt+F4, колесо мыши
  (IntelliMouse), пэйсинг ~50 fps, логи крутятся колесом;
  hotfix: куча ядра 2→16 МиБ, деградация вместо паники
- 🛠️ **v0.7.0 (текущая)** — Установщик при запуске + Центр обновления;
  Настройки: разрешение экрана (через UEFI NVRAM + перезагрузка через
  ResetSystem), масштаб 100/150/200%, 5 обоев, скорость/ускорение мыши;
  ramfs-ФС: создать папку/файл мышкой, читать и дописывать (мини-редактор);
  таймер 1000 Гц → 60 fps; мышь с накоплением дробной части и ускорением;
  русская раскладка клавиатуры (Alt+Shift); UEFI Runtime Services из ядра
- 🔜 **M6 (следующий)** — диск и файловая система: AHCI, блочный кэш, FAT32,
  сохранение ramfs на диск
- ⬜ **M7** — пользовательский режим (ring 3, системные вызовы)
- ⬜ **M8** — подсистема PE / WinAPI: совместимость с Windows .exe

Полный план: [docs/ROADMAP.md](docs/ROADMAP.md)

## Возможности

**Загрузка и ядро**
- Собственный UEFI-загрузчик: встроенный kernel.elf внутри BOOTX64.EFI,
  без gnu-efi и сторонних библиотек
- Framebuffer-консоль 1024×768 с UTF-8 кириллицей (свой шрифт 8×8)
- Дампы исключений с самодиагностикой: расшифровка error-code, векторов,
  селекторов, канарейка стека

**Память**
- PMM на bitmap → собственные таблицы страниц → kernel heap
- Нагружённая проверка кучи: миллион операций alloc/free, утечек нет

**Прерывания, время, ввод**
- ACPI: RSDP через EFI Configuration Table, парсинг MADT
- LAPIC-таймер 1000 Гц (калибровка по PIT, двойной замер, авто-откат на
  legacy PIC + PIT при неадекватной калибровке) — тик 1 мс для 60 fps
- IOAPIC: клавиатура (GSI→33) и мышь (GSI→44)
- Клавиатура PS/2: scancode→ASCII, Shift/CapsLock, F1..F10, стрелки, Ctrl,
  PgUp/PgDn, **русская раскладка (Alt+Shift)**; мышь PS/2: пакеты с
  ресинхронизацией, границы экрана, **настраиваемая скорость и ускорение**

**Многозадачность**
- Планировщик round-robin: вытеснение тиком, квант 4 тика, sleep/wake
- Ядровые потоки на отдельных стеках 32 КиБ; фоновые демоны heartbeat/sysmon

**Рабочий стол «glass aurora»**
- **Каждое окно — отдельный процесс ядра** (видно в Диспетчере: `w:Инфо`,
  `w:Задачи`, `w:Логи`, `w:Файлы`, `w:Текст`); одно и то же приложение можно
  открыть несколько раз — окна каскадом, до 10 одновременно
- Стеклянный UI: альфа-полупрозрачные панель/док/тени, скруглённые углы
  (r=8..14), «светофор» кнопок в заголовке, подсветка под курсором,
  подскок иконок в доке
- Ноль мерцания: весь стол рисуется в RAM-буфере (двойная буферизация), на
  видеопамять выливается один объединённый регион изменений, пэйсинг
  **60 fps**; курсор движется отдельными тычками — летает всегда
- Окна: перетаскивание за заголовок (без «хвостов»), поднятие по клику,
  закрытие красной ×, **Esc** или **Alt+F4**
- Панель: кнопки запуска (Инфо / Задачи / Логи / Файлы / Опции / Устан.),
  живые часы, индикатор раскладки RU/EN; плавающий док с иконками
- Колесо мыши (IntelliMouse PS/2): прокрутка логов и просмотра файлов
- Приложения: «О системе AresOS», «Диспетчер задач», «Логи системы»,
  «Проводник» (настоящая ramfs: создать папку/файл, читать, редактировать),
  «Настройки» (экран/масштаб/обои/мышь, сохранение в UEFI NVRAM),
  «Установка» (мастер установки + Центр обновления)
- Клавиатурная мышь: Ctrl+стрелки (спасение курсора в виртуалках)

**PE**
- Запуск настоящего PE32+ `TESTPE.EXE`: загрузка секций, импорты, вход —
  программа рисует шахматку прямо на рабочем столе

## Скачать и запустить

Готовые образы лежат в [dist/](dist/) (контрольные суммы — в
[SHA256SUMS.txt](dist/SHA256SUMS.txt)).

### VirtualBox — самый простой путь (ISO)

1. Скачать
   **[aresos-iso-v0.7.0.zip](https://github.com/Poncho435/AresOS/raw/arena/01a02ad5-aresos/dist/aresos-iso-v0.7.0.zip)**
   и распаковать — внутри один файл `aresos.iso`.
2. Создать ВМ: Тип **Other**, Версия **Other/Unknown (64-bit)**, 256+ МБ ОЗУ,
   **✔ Включить EFI** (Настройки → Система). Жёсткий диск не нужен.
3. Настройки → Система → **Манипулятор курсора: «PS/2 мышь»** — важно:
   наш драйвер работает именно с ней (USB-планшет пока не поддерживается).
4. Настройки → Носители → прикрепить `aresos.iso` к CD-приводу.
5. Запустить и **кликнуть внутрь окна ВМ**, чтобы VirtualBox захватил мышь.

### ВМ как готовый диск (VMDK)

**[aresos-vm-v0.7.0.zip](https://github.com/Poncho435/AresOS/raw/arena/01a02ad5-aresos/dist/aresos-vm-v0.7.0.zip)**
→ распаковать → в «Носителях» прикрепить `aresos.vmdk` к SATA → Запустить.

### Реальное железо (флешка)

**[aresos-usb-v0.7.0.zip](https://github.com/Poncho435/AresOS/raw/arena/01a02ad5-aresos/dist/aresos-usb-v0.7.0.zip)**
→ записать `aresos.img` на флешку (balenaEtcher / Rufus в DD-режиме)
→ Boot Menu → «UEFI: флешка». Пошаговая инструкция и чек-лист:
[docs/REALHARDWARE.md](docs/REALHARDWARE.md).

## Управление на рабочем столе

| Действие | Как |
|---|---|
| Запустить приложение | иконка на столе, иконка в доке, кнопка в панели или F1–F6 (F5 = Настройки, F6 = Установка) |
| Запустить ЕЩЁ одно такое же окно | нажать запуск повторно — окна множатся каскадом |
| Закрыть верхнее окно | **Alt+F4**, Esc или красная × в заголовке |
| Передвинуть окно | потянуть за заголовок |
| Проводник | «Файлы»: клик — зайти/открыть, кнопки «+ Папка» «+ Файл» — создать свои |
| Правка файла | «Изменить» → дописать текст → **F2 / «Сохранить»** |
| Русская раскладка | **Alt+Shift** (индикатор RU/EN в панели) |
| Настройки | F5: разрешение, масштаб 100/150/200%, обои, скорость мыши |
| Прокрутка логов и файлов | **колесо мыши**, а также ↑ / ↓, PgUp / PgDn |
| Курсор с клавиатуры | Ctrl + стрелки |

> **Про мышь в VirtualBox:** кликните внутрь окна ВМ для захвата указателя —
> удобнее всего работать в полном экране (Host+F). Если курсор «упёрся в
> край» или «утёк», дотянитесь до него клавишами **Ctrl+стрелки**: это
> ограничение VirtualBox без гостевых дополнений, а не баг AresOS.

## Сборка из исходников

```bash
make tools-check   # проверка окружения
make               # build/aresos.img (GPT-диск с ESP/FAT32) + build/aresos.iso
make run           # QEMU + OVMF (UEFI): окно эмулятора + serial-лог ядра
make debug         # + GDB-stub на :1234, далее `make gdb`
```

Требования: `gcc`, `make`, `python3`, `qemu-system-x86`, `ovmf`.
Подробности (включая установку на Windows + WSL2): [docs/SETUP.md](docs/SETUP.md).
